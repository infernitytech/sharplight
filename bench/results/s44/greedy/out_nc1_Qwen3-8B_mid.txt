# Sharplight An inference engine for large language models, ONNX models and, increasingly, every other model kind (speech, image generation, vision, ...), written in C# for .NET 11, with a Vulkan GPU backend (Slang compute kernels, cooperative-matrix tensor cores where available) and a CPU backend. - **Models:** GGUF and Hugging Face checkpoints for the llama.cpp architecture families ([docs/model-support.md](docs/model-support.md)), ONNX models including data-dependent shapes and control flow ([docs/onnx-support.md](docs/onnx-support.md)). - **Serving:** OpenAI- and Anthropic-compatible HTTP APIs for ASP.NET Core (`Sharplight.AspNetCore`), continuous batching, paged KV cache with prefix sharing, quantized KV cache ([docs/kv-cache.md](docs/kv-cache.md)), `Microsoft.Extensions.AI` adapters ([docs/extensions-ai.md](docs/extensions-ai.md)). - **Model packages:** the `.slm` format stores optimized, device-independent graphs and weights, plus optional precompiled artifacts per execution provider (SPIR-V, driver binaries) ([docs/model-format.md](docs/model-format.md)). It holds every model kind: a model description names the kind (text generation, speech recognition, speech synthesis, image generation, ...) and its components (encoder, decoder, tokenizer, denoiser, VAE, scheduler, ...), each with its graphs, weights, configuration and attachments. - **Task layer:** one client pattern for every model kind (`ITextGenerator`, `ISpeechRecognizer`, `ISpeechSynthesizer`, `IImageGenerator`), registered with `services.AddSharplight()` and Microsoft.Extensions.DependencyInjection ([docs/api-overview.md](docs/api-overview.md#tasks-one-model-concept-one-client-pattern)). Speech and image models are being brought up on it. Start with the [public API overview](docs/api-overview.md).
