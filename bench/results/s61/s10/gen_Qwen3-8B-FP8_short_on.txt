Explain how a hash table works in a few sentences. A hash table is a data structure that stores key-value pairs, using a hash function to compute an index (or hash code) for each key. This index determines where the corresponding value is stored in an array. When retrieving a value, the hash function is applied to the key again to find the index, allowing for quick access. Collisions, where different keys produce the same index, are handled using techniques like chaining (linked lists) or open addressing (probing).
